# Plant Watering

Smart plant-watering prototype with environmental sensing, soil-moisture monitoring, irrigation control, TCP communication, and a Flutter mobile application.

📚 **Documentation:** https://pmembari.github.io/Plant-Watering/

The documentation is built with **MkDocs Material** and deployed with GitHub Pages.

## Repository layout

- `Hardware/` — controller and embedded-development code
- `Flutter coding/` — mobile application
- `images/` — project photos
- `docs/` — MkDocs documentation
- `readme.docx` — original legacy documentation
